# พูดแปล (PhutPlae)

แอป iPhone ส่วนตัวสำหรับ **ฟังอย่างเดียว** ระหว่างทริปอังกฤษและจีน: ฟังภาษาอังกฤษหรือจีนกลางบนเครื่อง แล้วพูดคำแปลภาษาไทยพร้อมอารมณ์ ไม่มีโหมดสนทนาสองทาง ไม่พูดภาษาต่างประเทศแทนผู้ใช้

ทำงาน **ออฟไลน์ทั้งทริป** หลังดาวน์โหลดชุดภาษาครั้งเดียว (โหมดเครื่องบินใช้ได้) UI เป็น HUD สไตล์ JARVIS

## สิ่งที่แอปทำ

1. จับไมค์ด้วย `AVAudioEngine` + VAD ตัดประโยค
2. ถอดเสียงบนเครื่องด้วย **WhisperKit หลายภาษา** แล้วเดาว่าเป็น EN หรือ ZH
3. ถ้าเป็นไทยหรือภาษาอื่น จะข้าม ไม่แปล
4. อ่านอารมณ์จากคลื่นเสียงดิบด้วย **SER บนเครื่อง (emotion2vec+ seed → Core ML)** แล้วผสมกับฟีเจอร์เสียงสั้น + อารมณ์จากข้อความของ LLM โดยให้น้ำหนัก SER สูงสุด จากนั้นทำ EMA ตลอดประโยค และโชว์ค่าความมั่นใจเป็น %
5. แปลเป็นไทยบนเครื่อง
   - **อังกฤษ → ไทย:** Typhoon 2 3B Instruct 4-bit (SCB 10X) — จูนไทย
   - **จีนกลาง → ไทย:** Qwen 2.5 3B Instruct 4-bit — จีนกลางดีกว่า Typhoon
6. พูดไทยด้วย `AVSpeechSynthesizer` เสียง `th-TH` ปรับจังหวะตามอารมณ์
7. HUD: แกนปฏิกรณ์, กราฟ pitch/dB, ข้อความต้นทางแบบโมโนสเปซ, คำแปลไทยเรืองแสง, badge อารมณ์, ไฟ **OFFLINE READY**

โมเดล **ไม่ถูกฝังในแอป** จึงเล็กตอนติดตั้ง โหลดตอนมีเน็ตครั้งแรก แล้วเก็บในเครื่อง

## สิ่งที่ตรวจแล้ว / ยังตรวจไม่ได้

สภาพแวดล้อมนี้เป็น Linux ไม่มี Xcode จึง **ไม่ได้** `xcodebuild` และไม่ได้รันบน iPhone 17 Pro Max

ตรวจแล้วในระดับซอร์ส:

- โปรเจกต์ Xcode (`PhutPlae.xcodeproj`) iOS 18, iPhone only
- เทสตรอบอารมณ์→เสียง, ฟิวชัน SER/เสียง/ข้อความ, แมป 9 คลาสของ emotion2vec+, EMA ตามหน้าต่างเสียง, แกะ JSON แปล, สลับ Typhoon/Qwen ตามภาษา
- ไม่มีโหมดสองทาง / ข้อความหมุน 180° / วลีสำเร็จรูป

ยังต้องตรวจบน Mac + เครื่องจริง: ลิงก์ SPM (WhisperKit, mlx-swift-lm), ดาวน์โหลดน้ำหนัก, ไมค์, TTS, โหมดเครื่องบิน

## สร้างและลงเครื่อง (Apple ID ฟรี vs บัญชีจ่าย)

1. Mac + **Xcode 16+**
2. เปิด `PhutPlae.xcodeproj` รอ SPM ดึงแพ็กเกจ
3. Signing: ทีม = Apple ID ของคุณ, bundle `app.phutplae.PhutPlae`
4. เสียบ iPhone (แนะนำ **iPhone 17 Pro Max** จริง — MLX ต้องการ Apple Silicon)
5. ตั้งค่า → ความเป็นส่วนตัว → โหมดนักพัฒนา ถ้า iOS ถาม
6. Run

**Apple ID ฟรี:** ลงเครื่องตัวเองได้ ใบรับรองมีอายุประมาณ **7 วัน** แล้วต้องเสียบเครื่องกด Run ใหม่ จำกัดความสามารถบางอย่างแต่ไมค์+เครือข่ายใช้ได้

**Apple Developer จ่ายรายปี:** ใบรับรองยาวขึ้น แจกให้เครื่องตัวเองได้หลายเครื่องโดยไม่ต้องต่ออายุทุกสัปดาห์

ครั้งแรกต้องมีเน็ตเพื่อดึงโมเดล จากนั้นปิดเครื่องบินได้

## ดาวน์โหลดชุดภาษาก่อนเดินทาง

หน้า **ชุดภาษาก่อนเดินทาง** เปิดเองถ้ายังไม่มีไฟล์ หรือกด pill บน HUD / ตั้งค่า

| ชุด | ไฟล์ | ทำไม |
|---|---|---|
| ฟังเสียง EN+ZH | WhisperKit `base` หรือ `small` หลายภาษา | รุ่น `.en` ฟังจีนไม่ได้ |
| อังกฤษ → ไทย | `typhoon-ai/llama3.2-typhoon2-3b-instruct-mlx-4bit` | Typhoon จูนไทย |
| จีนกลาง → ไทย | `mlx-community/Qwen2.5-3B-Instruct-4bit` | Qwen แข็งจีนกลาง |
| อ่านอารมณ์จากเสียง | emotion2vec+ seed เป็น Core ML | ไม่ผูกภาษา ใช้ได้ทั้ง EN และ ZH |

แนะนำโหลดครบทุกชุดที่โรงแรม/บ้าน แล้วดู HUD เป็น `OFFLINE READY` ก่อนขึ้นเครื่อง

ตั้งค่านโยบายแปล: อัตโนมัติตามภาษา (แนะนำ) / บังคับ Typhoon / บังคับ Qwen

## โมเดล SER (อารมณ์จากเสียง)

เลือก **emotion2vec+ seed** (`emotion2vec/emotion2vec_plus_seed`) เพราะเป็นโมเดลอ่านอารมณ์จากคลื่น 16 kHz โดยตรง ไม่ผูกภาษา (ออกแบบมาให้ข้ามภาษาและไมค์ต่างกัน) และเป็นรุ่นเล็กสุดในตระกูลที่ยังเป็น foundation SER

| รายการ | ค่า |
|---|---|
| ทำไมไม่ใช้แค่ RMS/pitch | ฟีเจอร์มือยังสับสนโกรธกับดีใจ และไม่ทนสำเนียงจีนกลาง |
| ทำไมไม่ใช้ wav2vec2 อังกฤษอย่างเดียว | รุ่นที่ฮิตบน Hugging Face ส่วนใหญ่จูน IEMOCAP/RAVDESS ภาษาอังกฤษ |
| ขนาดพารามิเตอร์ | น้อยกว่า emotion2vec+ base (~90M) — seed จูนบนข้อมูลวิชาการ 201 ชั่วโมง |
| ขนาดไฟล์บนเครื่อง | Core ML float16 ประมาณ **80–140 MB** (ไม่ฝังในแอป โหลดเป็นชุดภาษา) |
| คลาสต้นทาง | 9: angry, disgusted, fearful, happy, neutral, other, sad, surprised, unknown |
| คลาสที่ใช้ในแอป | 6: ปกติ โกรธ ดีใจ เศร้า กลัว ตกใจ — disgust ถูกพับเข้าโกรธ/กลัว, other/unknown ทิ้งแล้วปรับผลรวมใหม่ |
| ความแม่นยำที่คาด | งานต้นฉบับอ้างว่าดีกว่าโมเดล SER โอเพนซอร์สยอดนิยมบน Hub; สำหรับ 6 คลาสในห้องจริงคาด **UAR ประมาณ 60–70%** ดีกว่าฟีเจอร์เสียง+ข้อความอย่างเดียว โดยเฉพาะโกรธ/เศร้า/ตกใจ |
| ความหน่วง | ประโยคสั้นรันหน้าต่าง 2 วินาที ซ้อน 0.5 วินาที คู่ขนานกับ Whisper — มักไม่เพิ่มเวลารวม |
| น้ำหนักฟิวชัน | SER 0.62 · เสียง 0.18 · ข้อความ LLM 0.20 แล้วทำ EMA ทั้งประโยค |

แปลงบน Mac ครั้งหนึ่งแล้วคัดลอก `.mlpackage` เข้าเครื่อง (หรือให้แอปดึง zip ถ้าคุณโฮสต์ไฟล์ที่แปลงแล้ว):

```
python3 scripts/convert_emotion2vec_seed_to_coreml.py --out Emotion2VecPlusSeed.mlpackage
```

ถ้า Hub ยังไม่มี zip ของ Core ML แอปจะดึง `model.pt` ไว้ก่อน แล้วต้องแปลงบน Mac ตามสคริปต์ด้านบน ก่อนเดินทางให้เห็นชุด SER เป็น `ON DISK`

## เสียงไทย Enhanced

แอปใช้เฉพาะ TTS ไทย และเลือกเสียง Enhanced/Premium ให้อัตโนมัติถ้ามี

**การตั้งค่า → การช่วยการเข้าถึง → พูดเนื้อหา → เสียง → ไทย → ดาวน์โหลด Enhanced**

แล้วเปิดแอปใหม่

## Cold start และแรม

เซสชันสั้นกว่า 3 นาที:

- เปิดแอปแล้วบูตโมเดลทันที แกนปฏิกรณ์หมุนสถานะ `BOOT`
- พร้อมแล้วขึ้น `READY` จึงกดฟังได้
- เข้าเบื้องหลัง: หยุดฟัง และถอดโมเดลออกจากแรม
- กลับมาโฟร์กราวด์: บูตจากดิสก์อีกครั้ง ไม่ใช้เน็ตถ้าโหลดไว้แล้ว

โหมดอัตโนมัติเก็บแปลตัวเดียวในแรม แล้วสลับ Typhoon/Qwen จากดิสก์เมื่อภาษาเปลี่ยน

## ความหน่วงที่คาด (iPhone 17 Pro Max)

| ขั้น | ประมาณ |
|---|---|
| VAD ตัดประโยค | 0.3–0.6 วินาที หลังเงียบ |
| Whisper base | 0.3–1.2 วินาที / ประโยคสั้น |
| แปล 3B 4-bit | 0.8–2.5 วินาที |
| TTS ไทย | เกือบทันที |
| รวมหลังพูดจบ | ประมาณ 1.5–4 วินาที |

ครั้งแรกของแต่ละชุดช้าเพราะดาวน์โหลด ครั้งถัดไปอ่านดิสก์

## ข้อจำกัด

- ไม่ใช่ล่ามสองทาง ไม่พูดอังกฤษ/จีนแทนคุณ
- อารมณ์ของ TTS ระบบเป็นจังหวะ/ระดับเสียง ไม่ใช่โมเดลน้ำเสียง
- ห้องดัง สำเนียงท้องถิ่นจีน หรือสแลงหนัก อาจเพี้ยน
- ซิมูเลเตอร์ x86 มักรัน MLX ไม่ได้ ใช้เครื่องจริง
- โมเดล 3B กินแรมและร้อนเครื่อง
- ใบรับรองฟรีหมดอายุประมาณ 7 วัน

## รันเทสต์บน Mac

```
xcodebuild -scheme PhutPlae -destination 'platform=iOS Simulator,name=iPhone 17 Pro Max' test
```

เทสต์ที่รวมไว้: จับคู่ EN→Typhoon / ZH→Qwen, เดาภาษาจากตัวอักษร, แมปอารมณ์→เสียง, แกะ JSON แปล
